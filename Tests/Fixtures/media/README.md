# Native media export fixtures

Generated by `scripts/capture-media-fixtures.py` using ImageIO and ffmpeg.
`metadata.jpg` is a 64×48 synthetic image with fixture camera/date/GPS metadata.
`bordered.mp4` is one second of a red 160×100 rectangle in a 200×140 black frame.
No personal media is used. Real engine EXIF, transcode and crop reports are captured
in `../czkawka/`. These inputs verify source immutability, metadata removal and
actual encoded/cropped dimensions.
