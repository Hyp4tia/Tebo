Tebo: first launch
=================

INSTALL
-------
Drag Tebo.app onto the Applications shortcut, then open Tebo from Applications.
Official release packages are signed, notarized and stapled by the release process.

FULL DISK ACCESS
----------------
Folder and media scans work on locations macOS lets Tebo read. For broader Clean
coverage, grant Full Disk Access in System Settings -> Privacy & Security ->
Full Disk Access, add Tebo from Applications, enable it, then relaunch Tebo.
Protected or unreadable locations can produce partial results without this access.
Tebo never asks for an administrator password or elevates privileges.

UPDATES
-------
Use Tebo -> Check for Updates, or Settings -> Updates. Automatic update checks
can be enabled or disabled there. Updates come from the official GitHub releases
and require valid cryptographic signatures before installation. Builds predating
1.2 need one manual download to receive the updater.

CLEANUP AND RECOVERY
--------------------
Preview is on by default. Scanning is read-only, and every offered row comes from
an actual scan. Confirmed removals go to the Trash. Use Finder's Trash -> Put Back
to recover an item before emptying the Trash. Media exports create new copies.
Operations are logged in ~/Library/Logs/tebo/operations.log.

PRIVACY AND CREDITS
-------------------
Scans and media processing remain local. The updater contacts GitHub to check for
and download releases; system profiling and telemetry are disabled. Video helpers
are included, so no separate Homebrew installation is required.
See NOTICE.md, LICENSE and VideoHelpers inside the app bundle for attribution.

UNINSTALL
---------
Move Tebo from Applications to the Trash. Optional saved configuration and logs
are in ~/.config/tebo and ~/Library/Logs/tebo; review them in Finder before removal.
